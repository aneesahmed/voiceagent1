Getting started

  1. Get a Gemini API key from aistudio.google.com/apikey and paste it below -- this is the only thing required to use Web Testing.
  2. Everything else on this page (Twilio) is optional -- only needed if you want a real phone number, or the browser-based Twilio Testing page.
  3. For Twilio: create a free trial account at twilio.com/try-twilio, buy a U.S. number, and grab the Account SID + Auth Token from your Twilio console's home page.
  4. Run a public tunnel to this backend (e.g. a Cloudflare quick tunnel: cloudflared tunnel --url http://localhost:8001, no account needed) and open this Settings page through that tunnel URL so the webhook URL below is detected correctly.
  5. Paste the webhook URL shown below into your Twilio number's Voice configuration -- see the exact steps under "Real Call Settings" below.
